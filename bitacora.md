## Cual es la diferencia en tre git commit y git add

la principal difenrencias podemos verla a traves de una analogia, tenemos distintas fotos regadas por toda una mesa (las podemos ver como los archivos y los cambios q hacemos dentro de nuestro proyecto) nosotros con git add elegimos que fotos queremos guardar en nuestro album (repo) a traves del comando git commmit y esto se guarda dentro del album, luego somos nosotros con git push que guardamos ese album dentro de nuestro repo.
